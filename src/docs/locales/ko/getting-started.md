## 첫 플랫폼을 단계별로 시작하기

**Bootstrapper**는 플랫폼을 실행합니다. **Wizard**는 브라우저에서 플랫폼을 구성합니다. **Sync**는 둘을 연결합니다. Kubernetes 경험은 필요하지 않습니다.

1. sudo, curl, 인터넷, 최소 8 GiB RAM 및 40 GiB의 여유 디스크 공간이 있는 새 Ubuntu 24.04 / 26.04 LTS x86_64 호스트에서 [빠른 설치](#docs/quickstart)를 진행하세요. 또는 [Ubuntu/WSL2 수동 설치](#docs/installation)나 공개 서버용 HTTPS 절차를 선택하세요.
2. [연결 및 구성](#docs/configuration)을 진행하세요. **Wizard**를 열고 **연결** 옆의 연필을 선택한 뒤, 자신의 Sync 주소와 자격 증명을 입력하고 **적용 → 동기화 → 가져오기**를 실행하세요.
3. 설정을 검토하고 비공개 **백업**을 보관한 다음 **보내기**를 실행하세요. 보내기는 구성을 적용하고 서비스를 자동으로 다시 시작합니다.
4. [Runner를 설정](#docs/runners)한 다음 [첫 프로젝트를 생성](#docs/projects)하세요. 빌드 및 배포 작업이 끝난 뒤 프로젝트 도메인을 여세요.

> **팁:** 먼저 로컬 HTTP로 작업 흐름을 익히세요. 서비스를 인터넷에 노출하기 전에 공개 서버 가이드 전체를 따르세요.

## 두 종류의 백업 보관하기

**열기 / 백업**과 **가져오기 / 보내기**는 비밀 정보를 포함한 구성을 관리합니다. **Harvest / Seed**는 영구 서비스 데이터를 보호합니다. 구성 ZIP에는 GitLab 데이터베이스나 저장소가 포함되지 않습니다. 백업에 의존하기 전에 [복구](#docs/recovery)를 확인하세요.

## 시작 환경 확인하기

Ubuntu 콘솔에서 다음 명령을 실행하세요.

```bash
uname -m
git --version
```

공개 릴리스의 대상은 `x86_64` / `linux/amd64`입니다. 빠른 설치는 검증된 릴리스를 다운로드하고 초기 Wizard를 시작합니다. 보호된 최초 접속 안내를 따른 뒤 브라우저에서 계속하세요. 다운로드와 초기화에는 시간이 걸립니다. 수동 설치 장에서는 Git, Docker, 릴리스 입력값 및 확인 절차를 설명합니다. 기존 설치와 Seed 복구는 각각 별도로 문서화된 절차를 사용합니다.

> **정보:** 예제 도메인과 릴리스 자리표시자는 자신의 배포에 맞게 지정해야 합니다. 독립 실행형 Wizard는 Sync, GitLab 또는 Runner를 시작하지 않습니다.
