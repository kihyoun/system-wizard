## 플랫폼의 구성 요소

| 구성 요소 | 역할 |
| --- | --- |
| Bootstrapper | 컨테이너와 영구 저장소를 시작하고 조정합니다. |
| Wizard | 설정, Runner, 프로젝트를 관리하는 브라우저 인터페이스입니다. |
| Sync | Wizard와 Bootstrapper 사이의 인증된 API입니다. |
| GitLab | 소스 저장소, 병합 요청, 파이프라인을 관리합니다. |
| Runner 관리자 | 공유 Runner 풀에서 파이프라인 작업을 실행합니다. |
| Registry | 파이프라인이 빌드한 컨테이너 이미지를 저장합니다. |
| NGINX | 설정된 각 도메인을 해당 서비스나 환경으로 연결합니다. |

## 안전한 설정 변경 순서

**연결 → 가져오기 → 편집 → 백업 → 전송 → 다시 연결 → 가져오기.** 가져오기는 저장된 설정을 불러오며, 처음 설정할 때는 제안임을 표시한 값을 불러옵니다. 전송하기 전에 제안 내용을 확인하세요. 전송은 설정을 적용하고 서비스를 자동으로 다시 시작합니다.

> **경고:** 백업 파일에는 인증 정보가 들어 있습니다. 비공개로 보관하세요. 설정 백업과 완료된 서비스 데이터 Seed는 별개의 복구 입력입니다.

## 변경 후에도 남는 것

소스와 이미지는 인프라를 정의합니다. 영구 서비스 데이터에는 저장소, 데이터베이스, Registry 내용과 비밀 값이 들어 있습니다. 저장된 설정은 최초 설치 예시보다 우선합니다. [운영 저장소](#docs/storage)에서 로컬 데이터, 선택적인 운영 볼륨과 별도 백업 매체를 설명합니다.

## 빌드, 검증, 승격

소스 가져오기는 소스를 설치하고, 빌드는 후보를 생성합니다. Review와 Beta는 선택적인 환경입니다. 프로덕션 승격은 정확한 이미지 근거와 되돌리기 체크포인트를 사용하는 별도의 명시적인 작업입니다. 전체 플랫폼에 대해서는 [시스템 발전](#docs/evolution)을, 인터페이스 배포에 대해서는 연결된 Wizard 안내서를 따르세요.
